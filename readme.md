
# BookStore REST API with Pydantic Validation

## Project Overview
An asynchronous CRUD REST API developed using
Python and FastAPI to manage bookstore records.

## Features
- Add new books
- Retrieve all books
- Retrieve individual books
- Update book details
- Delete books
- Pydantic data validation
- Query parameter filtering
- HTTP error handling
- Automatic Swagger documentation

## Technologies Used
- Python 3
- FastAPI
- Pydantic
- Uvicorn

## Installation

pip install -r requirements.txt

## Run the Application

uvicorn main:app --reload

## API Documentation

http://127.0.0.1:8000/docs
